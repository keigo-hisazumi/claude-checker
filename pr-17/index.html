Claude Usage Checker

Claude Code のローカル使用ログ(JSONL)を読み込み、トークン使用量と推定コストを可視化します。

🔒 データはすべてブラウザ内で処理され、外部には一切送信されません。

1. ログを読み込む

Claude Code の使用ログは ~/.claude/projects/ 配下に JSONL ファイルとして保存されています。 フォルダごと選択するか、.jsonl ファイルをドラッグ&ドロップしてください。

※ コストは公開されている API 料金(USD)に基づく推定値です。 キャッシュ書込は入力単価の 1.25 倍(5 分 TTL)、キャッシュ読取は 0.1 倍で計算しています。 サブスクリプション(Pro / Max)利用時の実際の請求額とは異なります。

ログの重複エントリは message.id + requestId で除外しています。
